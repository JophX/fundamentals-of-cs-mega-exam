Collection of definitions
Theorem 1 (The regular pumping lemma) .Let L be a (usually infinite) regular language. Then there exists
some positive integer n such that any w ∈L with ∣w∣≥n can be decomposed as w =xyz, with ∣xy∣≤n and ∣y∣≥1,
such that w i=xyiz, is also in L for all i ≥0.
Theorem 2 (The context-free pumping lemma) .Let L be an (infinite) context-free language. Then there exists
some positive integer n such that any w ∈L with ∣w∣≥n can be decomposed as w =xuyvz with ∣uyv∣≤n and
∣uv∣≥1such that xuiyviz∈L for all i∈N(including 0).
Definition 1. Anondeterministic pushdown automaton (NPDA) is a septuple M=(Q,Σ,Γ,δ,q0,z,F)where:
•Qis a finite set of states,
•Σis the input alphabet,
•Γis a finite set of symbols called the stack alphabet ,
•δ∶Q×(Σ∪{λ})×Γ→2Q×Γ∗, where each set in the range is finite, is the transition function,
•q0∈Qis the initial state,
•z∈Γis the stack start symbol ,
•F⊆Qis the set of final states.
Definition 2. A deterministic single-tape Turing machine Mis defined by M=(Q,Σ,Γ,δ,q0,◻,F), where
•Qis the set of states,
•Σis the input alphabet,
•Γis a finite set of symbols called the tape alphabet ,
•δis the transition function defined as δ∶Q×Γ→Q×Γ×{L,R}.
•◻∈Γis a special symbol called the (tape) blank , we assume that ◻∉Σ,
•q0∈Qis the initial state, and
•F⊆Qis the set of final states.
