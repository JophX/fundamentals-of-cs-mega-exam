7. The Grill — do these on paper, without looking

Set a timer. Write full answers as if on the exam. Answers start on the next page, so don’t turn it until you are done. Mark each question ✔ or ✘ and redo every ✘ tomorrow morning.

A. Chomsky normal form

  1. Which rules break CNF, and why? \(S\to AB\mid aB\mid a \quad A\to ABA\mid b \quad B\to B \mid \lambda \mid bb\)
  2. Convert to CNF: \(S\to aSa\mid bSb\mid\lambda\) (even-length palindromes).
  3. Convert to CNF: \(S\to AB\mid aB\qquad A\to aab\mid\lambda\qquad B\to bbA\)
  4. Convert to CNF: \(S\to A\mid aSb\qquad A\to bA\mid b\)
  5. In example B of section 1.3, why is \(S\) not nullable even though \(A\) is?

B. CYK

  1. Using your CNF grammar from question 2, run CYK on abba and on abab. Show the tables and explain the results.
  2. Using the exam grammar \(S\to SS\mid XY\mid XS'\), \(S'\to SY\), \(X\to a\), \(Y\to BC\mid BB\mid b\), \(B\to b\), \(C\to CC\mid c\): run CYK on aabbb and on abcca.
  3. How many cuts do you try for a cell of length 4? For the top cell of a string of length 6?

C. Theory — write complete answers (definition, mechanism, example, advantages)

  1. Explain encapsulation.
  2. Explain information hiding, and how it differs from encapsulation.
  3. What is abstraction? Name its two kinds.
  4. What is polymorphism? Name the three kinds with an example each.
  5. What does the lexer do, what is its output, and what data structures does it use?
  6. Describe the role of the parser in as much detail as you can.
  7. What does the executing part of an interpreter do and what data structures does it use?
  8. Explain precedence and associativity and how they are related. How does a grammar encode them?
  9. Pass-by-value vs pass-by-reference: differences, advantages, disadvantages. What does f(a, a) have to do with it?

D. Haskell — write these (type signature first!)

  1. foldl and foldr, from scratch.
  2. myRev in O(n), without library functions. Explain why it is O(n).
  3. listToInt :: [Int] -> Int ([1,2,3] → 123), once with an accumulator and once with foldl.
  4. compress :: String -> [(Char, Int)] and decompress :: [(Char, Int)] -> String.
  5. countOcc :: Eq a => a -> [a] -> Int — how many times does an element occur?
  6. myLength, tail-recursive.
  7. map and filter, written using foldr.
  8. sumSqOdd: the sum of the squares of the odd numbers in a list, using filter, map, foldl. What is sumSqOdd [1,2,3,4,5]?
  9. myLast, myMaximum, elemAt (the n-th element, counting from 0).
  10. isPal (is a list a palindrome?) and dedup (remove consecutive duplicates: [1,1,2,3,3,3,1] → [1,2,3,1]).
  11. myZip, myAppend (your own ++), myReplicate.
  12. Without a computer, what do these give?
    1. foldr (\x acc -> x : x : acc) [] [1,2,3]
    2. foldl (\acc x -> x : acc) [] "abc"
    3. foldr (\x acc -> acc + 1) 0 "hello"
    4. foldl (\acc x -> acc * 2 + x) 0 [1,0,1,1]
    5. foldl (-) 10 [1,2,3] and foldr (-) 10 [1,2,3]

E. Grammars (both 2023 exams had these — 20 points)

  1. Write a CFG for “equally many \(a\) and \(b\), and every prefix has at least as many \(a\) as \(b\)”.
  2. Write a CFG for \(\{a^nb^m\mid n\ne m\}\).
