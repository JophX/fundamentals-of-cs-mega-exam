2. The CYK algorithm: show the table, explain the result

The idea in plain words

Question: can the grammar produce the string \(w\)? CYK answers it bottom-up, like building a pyramid:

  • First, for every single letter: which variables can produce it? (Look for rules \(A\to a\).)
  • Then, for every piece of length 2: which variables can produce it? Because the grammar is in CNF, a variable produces a piece only through a rule \(A\to BC\): \(B\) makes the left part, \(C\) makes the right part. So try every place to cut the piece in two, and look up the two halves in the rows you already have.
  • Then length 3, 4, … up to the whole string.
  • At the top: if the start symbol can produce the whole string, \(w\in L(G)\).

That’s all. The grammar must be in CNF first (that’s why CNF and CYK always come together).

Definition (Linz notation — write this)

Let \(w = a_1a_2\cdots a_n\). Define \(V_{ij}\) = the set of variables that derive the substring \(a_i\cdots a_j\). Then \[V_{ii} = \{A \mid A\to a_i\}\] \[V_{ij} = \bigcup_{k=i}^{j-1}\{A \mid A\to BC,\ B\in V_{ik},\ C\in V_{k+1,j}\}\] and \(w\in L(G) \iff S\in V_{1n}\). The running time is \(O(n^3)\).

Recipe for the exam
  1. Check that the grammar is in CNF (say so explicitly — the exam often asks).
  2. Draw a triangle: row 1 has \(n\) cells (one per letter), row 2 has \(n-1\), …, the top row has one cell. Label each cell with its substring — this avoids mistakes.
  3. Row 1: for each letter, write the variables with a rule \(X\to\) that letter.
  4. Row \(\ell\): for each substring of length \(\ell\), for every cut into (left, right): take the pairs \(B\in\) cell(left), \(C\in\) cell(right), and add every \(A\) with a rule \(A\to BC\). Write ∅ if nothing.
  5. Top cell: contains \(S\)? Then write the conclusion sentence (below).
The “very briefly explain what the result means” sentence

“Cell \(V_{ij}\) contains exactly the variables that can derive the substring from position \(i\) to \(j\). Since the start symbol \(S\) is in the top cell \(V_{1n}\), \(S\Rightarrow^* w\), so the string is in the language of the grammar.” (If \(S\notin V_{1n}\): “…so the string is not in the language.”)

Bonus sentence for full points: “Following the entries back down (which cut produced \(S\)) gives a derivation tree.”

2.1 Worked example 1 — the real exam question (abcab)

Grammar: \(S\to SS\mid XY\mid XS'\), \(S'\to SY\), \(X\to a\), \(Y\to BC\mid BB\mid b\), \(B\to b\), \(C\to CC\mid c\).

Is it in CNF? Yes: every rule is either two variables (\(SS, XY, XS', SY, BC, BB, CC\)) or one terminal (\(a, b, c\)). (\(S'\) is just a variable name.) So the answer is “Yes”.

The mistakes that cost points

    
  
  • Not trying every cut. A cell of length \(\ell\) has \(\ell-1\) cuts. Example 1’s top cell has 4 cuts,
    and only the third one works.
    • 
  
  • Order matters: \(A\to BC\) needs \(B\) on the left part and \(C\) on the right part.
    • 
  
  • Forgetting that a cell can hold several variables (like \(\{B,Y\}\)) — try all of them.
    • 
  
  • Not writing the conclusion sentence. “Briefly explain what the result means” is worth points on its own.
    • 
  
  • Running CYK on a grammar that is not in CNF — convert first (section 1).
