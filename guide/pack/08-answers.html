A. Chomsky normal form

1. \(S\to AB\) ✔, \(S\to a\) ✔, \(A\to b\) ✔. Broken: \(S\to aB\) (terminal together with a variable), \(A\to ABA\) (three variables), \(B\to B\) (unit production — and pointless), \(B\to\lambda\) (λ-production), \(B\to bb\) (two terminals).

2. Nullable: \(\{S\}\). Remove λ: \(S\to aSa\mid aa\mid bSb\mid bb\). No units, nothing useless. Terminals \(A\to a\), \(B\to b\): \(S\to ASA\mid AA\mid BSB\mid BB\). Break the long ones:

Answer 2

\(S\to AX\mid BY\mid AA\mid BB\qquad X\to SA\qquad Y\to SB\qquad A\to a\qquad B\to b\)   (generates the language minus λ)

3. Nullable: \(\{A\}\) (not \(S\), not \(B\): both rules of each contain something non-nullable). Remove λ: \(S\to AB\mid B\mid aB\), \(A\to aab\), \(B\to bbA\mid bb\). Units: \(S\to B\) → \(S\) gets \(bbA, bb\); delete it: \(S\to AB\mid aB\mid bbA\mid bb\). Useless: none. Shapes with \(U\to a\), \(T\to b\): \(S\to AB\mid UB\mid TTA\mid TT\), \(A\to UUT\), \(B\to TTA\mid TT\); break \(TTA\) with \(W\to TA\) and \(UUT\) with \(V\to UT\):

Answer 3

\(S\to AB\mid UB\mid TW\mid TT\quad A\to UV\quad V\to UT\quad B\to TW\mid TT\quad W\to TA\quad U\to a\quad T\to b\)

The classic slip: forgetting to copy \(bbA\) into \(S\) when removing \(S\to B\).

4. No λ. Unit \(S\to A\): copy \(bA\), \(b\) into \(S\): \(S\to aSb\mid bA\mid b\), \(A\to bA\mid b\). Shapes with \(U\to a\), \(T\to b\), \(X\to ST\):

Answer 4

\(S\to UX\mid TA\mid b\qquad X\to ST\qquad A\to TA\mid b\qquad U\to a\qquad T\to b\)

5. \(S\to ASA\) could only vanish if \(S\) itself were already nullable (circular — never established), and \(S\to aB\) contains the terminal \(a\), which can never vanish.

E. Grammars


30

\(S\to aSbS\mid\lambda\). Why: a non-empty string of this language starts with an \(a\); match it with the \(b\) that
first brings the count back to zero. Between them is a balanced string (\(S\)), after the \(b\) is another balanced string
(\(S\)). Test: \(ab\): \(S\Rightarrow aSbS\Rightarrow abS\Rightarrow ab\) ✔; \(aababbab\) ✔; \(ba\) cannot start ✔.
(Also correct: \(S\to SS\mid aSb\mid\lambda\).)


31

\(S\to aSb\mid A\mid B\qquad A\to aA\mid a\qquad B\to bB\mid b\). Why: \(aSb\) builds the equal part from the outside
in; in the middle we must put at least one extra \(a\) (\(A\)) or at least one extra \(b\) (\(B\)). λ is correctly
excluded since \(A\), \(B\) never give λ.
