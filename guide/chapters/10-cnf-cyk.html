10. Chomsky normal form and the CYK algorithm BOTH

Part A — Chomsky normal form

The idea in plain words

A grammar in CNF is a grammar where every rule is one of only two boring shapes:

\(A \to BC\)  (exactly two variables)   or   \(A\to a\)  (exactly one terminal).

Why would anyone want that? Because then every derivation tree is a binary tree, and a string of length \(n\) is always derived in exactly \(2n-1\) steps. That makes algorithms like CYK (Part B) possible. Converting to CNF does not change the language (except that λ disappears) — it only rewrites the rules into boring shapes.

Definition (write this on the exam)

A context-free grammar is in Chomsky normal form if every production has the form \[A \to BC \qquad\text{or}\qquad A \to a\] where \(A, B, C\) are variables and \(a\) is a terminal. Every CFG \(G\) with \(\lambda\notin L(G)\) has an equivalent grammar in CNF. (If \(\lambda\in L(G)\), the CNF grammar generates \(L(G)\setminus\{\lambda\}\).)

Checking whether a grammar is in CNF

Go through the rules one by one and mark anything that is not of those two shapes:

RuleCNF?Why
\(S\to AB\)✔two variables
\(A\to a\)✔one terminal
\(S\to aB\)✘terminal mixed with a variable
\(S\to ABC\)✘three variables (too long)
\(A\to B\)✘a unit production (single variable)
\(A\to\lambda\)✘a λ-production
\(A\to ab\)✘two terminals

10.A1 The recipe (Linz order: λ → units → useless → shape)

Recipe: converting to CNF — always in this order
  1. Remove λ-productions.
    • Find the nullable variables: \(A\) is nullable if \(A\to\lambda\), or \(A\to B_1\dots B_k\) where all \(B_i\) are nullable. Repeat until nothing new.
    • For every rule, add all versions where you leave out any combination of nullable variables (but never add \(A\to\lambda\)).
    • Delete all \(A\to\lambda\).
  2. Remove unit productions (\(A\to B\)).
    • For every \(A\), find all \(B\) with \(A\Rightarrow^* B\) using only unit rules.
    • Give \(A\) a copy of every non-unit rule of each such \(B\).
    • Delete all unit rules (including \(A\to A\)).
  3. Remove useless variables, in this order:
    1. non-generating: variables that can never finish into a terminal string (e.g. \(C\to cC\) only);
    2. non-reachable: variables that can’t be reached from \(S\).
    Delete every rule that mentions them.
  4. Fix the shapes.
    1. In every rule whose right side has length ≥ 2, replace each terminal \(a\) by a new variable \(T_a\) and add \(T_a\to a\).
    2. Break every right side with 3 or more variables into a chain: \(A\to C_1C_2C_3\cdots C_n\) becomes \(A\to C_1D_1,\ D_1\to C_2D_2,\ \dots,\ D_{n-2}\to C_{n-1}C_n\).
Why the order matters

Removing λ can create unit rules (e.g. \(S\to aSb\mid SS\) with nullable \(S\) gives \(S\to S\)). Removing units can create useless variables (a variable nobody uses any more). So: λ first, units second, useless third, shapes last. If you do it in another order you will have to repeat steps.

10.A2 Worked example A — the exam’s own grammar \(S\to aSbS\mid\lambda\)

This is the grammar for the PL-exam language “equally many \(a\) and \(b\), every prefix has at least as many \(a\) as \(b\)”. Convert it to CNF.

Step 1 — λ-productions. Nullable: \(S\) (because \(S\to\lambda\)). The rule \(S\to aSbS\) contains two occurrences of \(S\), so we write all four combinations of keeping/dropping them:

keep 1st S?keep 2nd S?new rule
yesyes\(S\to aSbS\)
noyes\(S\to abS\)
yesno\(S\to aSb\)
nono\(S\to ab\)

Delete \(S\to\lambda\). Result: \(S\to aSbS\mid abS\mid aSb\mid ab\).

Step 2 — unit productions. None (no rule of the form \(S\to X\)). Step 3 — useless. None.

Step 4a — terminals. Introduce \(A\to a\) and \(B\to b\): \(S\to ASBS\mid ABS\mid ASB\mid AB\).

Step 4b — long right sides.

  • \(S\to ASBS\) (4 symbols) → \(S\to AX,\ X\to SW,\ W\to BS\).
  • \(S\to ABS\) (3 symbols) → \(S\to AY,\ Y\to BS\).
  • \(S\to ASB\) (3 symbols) → \(S\to AZ,\ Z\to SB\).
  • \(S\to AB\) is already fine.
Final answer

\(S\to AX\mid AY\mid AZ\mid AB\qquad X\to SW\qquad W\to BS\qquad Y\to BS\qquad Z\to SB\qquad A\to a\qquad B\to b\)

Since \(\lambda\) was in the original language, the CNF grammar generates the same language minus \(\lambda\). (You may reuse \(W\) instead of introducing \(Y\) — both are correct.)

10.A3 Worked example B — every step is needed

\(G:\quad S\to ASA\mid aB \qquad A\to B\mid S\qquad B\to b\mid\lambda\)

Step 1 — λ-productions.

  • Nullable: \(B\) (since \(B\to\lambda\)); then \(A\) (since \(A\to B\) and \(B\) is nullable). Is \(S\)? \(S\to ASA\) needs \(S\) itself nullable, \(S\to aB\) has a terminal. So no. Nullable \(=\{A,B\}\).
  • \(S\to ASA\): the two \(A\)’s may each be dropped: \(ASA,\ SA,\ AS,\ S\).
  • \(S\to aB\): drop \(B\): \(aB,\ a\).
  • \(A\to B\): dropping \(B\) would give \(A\to\lambda\) — never add that. \(A\to S\) unchanged.
  • Delete \(B\to\lambda\).

Result: \(S\to ASA\mid SA\mid AS\mid S\mid aB\mid a\qquad A\to B\mid S\qquad B\to b\)

Step 2 — unit productions. The unit rules are \(S\to S\), \(A\to B\), \(A\to S\).

  • \(S\to S\): just delete it.
  • \(A\Rightarrow^* B\) and \(A\Rightarrow^* S\). So \(A\) gets all non-unit rules of \(B\) (\(b\)) and of \(S\) (\(ASA, SA, AS, aB, a\)).

Result: \(S\to ASA\mid SA\mid AS\mid aB\mid a\qquad A\to b\mid ASA\mid SA\mid AS\mid aB\mid a\qquad B\to b\)

Step 3 — useless. Everything generates a terminal string and is reachable. Nothing to remove.

Step 4. \(aB\) → \(UB\) with \(U\to a\). \(ASA\) → \(AX\) with \(X\to SA\).

Final answer

\(S\to AX\mid SA\mid AS\mid UB\mid a\)
\(A\to b\mid AX\mid SA\mid AS\mid UB\mid a\)
\(B\to b\qquad U\to a\qquad X\to SA\)

10.A4 Worked example C — unit chains and useless variables

\(G:\quad S\to Aa\mid B\mid C\qquad A\to a\mid bA\qquad B\to A\mid bb\qquad C\to cC\)

  1. λ: no λ-rules. Skip.
  2. Units: \(S\to B\), \(S\to C\), \(B\to A\). Unit reachability: \(S\Rightarrow^* B, A, C\); \(B\Rightarrow^* A\). So \(S\) gets \(bb\) (from \(B\)), \(a, bA\) (from \(A\)), \(cC\) (from \(C\)); \(B\) gets \(a, bA\). Now: \(S\to Aa\mid bb\mid a\mid bA\mid cC\), \(A\to a\mid bA\), \(B\to bb\mid a\mid bA\), \(C\to cC\).
  3. Useless: (a) \(C\) is not generating — \(C\to cC\) never ends. Delete \(C\) and \(S\to cC\). (b) \(B\) is now unreachable — nobody mentions \(B\). Delete it. Now: \(S\to Aa\mid bb\mid a\mid bA\), \(A\to a\mid bA\).
  4. Shapes: \(V\to a\) and \(T\to b\): \(S\to AV\mid TT\mid a\mid TA\), \(A\to a\mid TA\).
Final answer

\(S\to AV\mid TT\mid a\mid TA\qquad A\to a\mid TA\qquad V\to a\qquad T\to b\)

Note: you cannot reuse \(A\) for “\(\to a\)” here, because \(A\) also has the rule \(A\to TA\); a new variable that only produces \(a\) is required.

The mistakes that cost points
  • Dropping only one combination of nullable symbols. With two nullable symbols in a rule there are up to 4 versions (with three, up to 8). Make the little table.
  • Adding \(A\to\lambda\) back by dropping everything.
  • Forgetting that a variable is nullable indirectly (\(A\to B\), \(B\to\lambda\)).
  • Removing a unit rule without copying the rules over (then the language shrinks).
  • Replacing a terminal by a variable that has other rules too (see example C).
  • Not saying anything about λ. One sentence: “λ ∈ L(G), so the CNF grammar generates L(G) − {λ}.”

Part B — The CYK algorithm



The idea in plain words

Question: can the grammar produce the string \(w\)? CYK answers it bottom-up, like building a pyramid:


    
  
  • First, for every single letter: which variables can produce it? (Look for rules \(A\to a\).)
    • 
  
  • Then, for every piece of length 2: which variables can produce it? Because the grammar is in CNF, a
    variable produces a piece only through a rule \(A\to BC\): \(B\) makes the left part, \(C\) makes the right
    part. So try every place to cut the piece in two, and look up the two halves in the rows you already
    have.
    • 
  
  • Then length 3, 4, … up to the whole string.
    • 
  
  • At the top: if the start symbol can produce the whole string, \(w\in L(G)\).
    • 



That’s all. The grammar must be in CNF first (that’s why CNF and CYK always come together).





Definition (Linz notation — write this)

Let \(w = a_1a_2\cdots a_n\). Define \(V_{ij}\) = the set of variables that derive the substring
\(a_i\cdots a_j\). Then
\[V_{ii} = \{A \mid A\to a_i\}\]
\[V_{ij} = \bigcup_{k=i}^{j-1}\{A \mid A\to BC,\ B\in V_{ik},\ C\in V_{k+1,j}\}\]
and \(w\in L(G) \iff S\in V_{1n}\). The running time is \(O(n^3)\).





Recipe for the exam

    
  
  1. Check that the grammar is in CNF (say so explicitly — the exam often asks).
    2. 
  
  2. Draw a triangle: row 1 has \(n\) cells (one per letter), row 2 has \(n-1\), …, the top row has one cell.
    Label each cell with its substring — this avoids mistakes.
    3. 
  
  3. Row 1: for each letter, write the variables with a rule \(X\to\) that letter.
    4. 
  
  4. Row \(\ell\): for each substring of length \(\ell\), for every cut into (left, right): take the pairs
    \(B\in\) cell(left), \(C\in\) cell(right), and add every \(A\) with a rule \(A\to BC\). Write ∅ if nothing.
    5. 
  
  5. Top cell: contains \(S\)? Then write the conclusion sentence (below).
    6. 






The “very briefly explain what the result means” sentence

“Cell \(V_{ij}\) contains exactly the variables that can derive the substring from position \(i\) to \(j\).
Since the start symbol \(S\) is in the top cell \(V_{1n}\), \(S\Rightarrow^* w\), so the string is in the
language of the grammar.” (If \(S\notin V_{1n}\): “…so the string is not in the language.”)


Bonus sentence for full points: “Following the entries back down (which cut produced \(S\)) gives a derivation
tree.”

The mistakes that cost points

    
  
  • Not trying every cut. A cell of length \(\ell\) has \(\ell-1\) cuts. Example 1’s top cell has 4 cuts,
    and only the third one works.
    • 
  
  • Order matters: \(A\to BC\) needs \(B\) on the left part and \(C\) on the right part.
    • 
  
  • Forgetting that a cell can hold several variables (like \(\{B,Y\}\)) — try all of them.
    • 
  
  • Not writing the conclusion sentence. “Briefly explain what the result means” is worth points on its own.
    • 
  
  • Running CYK on a grammar that is not in CNF — convert first (Part A).
