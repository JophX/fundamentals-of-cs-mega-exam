12. Turing machines and the language hierarchy FCS

Intuition: the simplest possible computer

A Turing machine is a finite automaton that can read and write on an infinite tape and move both ways. That is enough to compute anything any computer can compute (Church–Turing thesis). Unlike a DFA it may never stop.

Definition (exam appendix)

\(M=(Q,\Sigma,\Gamma,\delta,q_0,\square,F)\): states, input alphabet, tape alphabet \(\Gamma\supseteq\Sigma\cup\{\square\}\), transition function \(\delta:Q\times\Gamma\to Q\times\Gamma\times\{L,R\}\) (partial), start state, blank \(\square\notin\Sigma\), final states.

\(\delta(q,a)=(p,b,R)\): in state \(q\) reading \(a\): write \(b\), move right, go to \(p\). The machine halts when \(\delta\) is undefined. (Linz) it accepts \(w\) if it halts in a final state. An instantaneous description \(x\,q\,y\) means: tape contents \(xy\), state \(q\), head on the first symbol of \(y\).

Example: accept \(\{a^nb^n\mid n\ge1\}\)

Idea: repeatedly cross off the leftmost \(a\) (write \(x\)) and the leftmost \(b\) (write \(y\)).

StateDoes

Model answer — FCS Q7 (6 p): “Why NTMs are not more powerful than DTMs”

Every DTM is an NTM with one choice, so NTMs are at least as powerful. Conversely, let \(N\) be an NTM. The computations of
\(N\) on input \(w\) form a tree: each node is a configuration (ID), its children are the configurations reachable in one move;
since \(\delta\) gives finitely many choices, each node has at most \(k\) children. \(N\) accepts \(w\) iff some node of the tree
is an accepting configuration. A deterministic machine \(D\) (conveniently with 3 tapes: input, simulation, choice-sequence) explores
this tree breadth-first: for \(\ell=1,2,3,\dots\) it tries every sequence of choices of length \(\ell\), simulating \(N\)
on \(w\) following those choices. If \(N\) has an accepting computation of length \(\ell\), \(D\) finds it at stage \(\ell\) and
accepts; otherwise \(D\) never accepts. (Breadth-first, not depth-first, since one branch can be infinite.) Multitape DTMs are
equivalent to single-tape DTMs, so \(L(N)\) is accepted by a DTM. The price is time: up to \(k^{\ell}\) branches, an exponential
slowdown — but the set of languages is the same.





12.3 The universal Turing machine


Encode any TM \(M\) as a binary string \(\langle M\rangle\) (list its transitions). A universal TM \(U\) takes
\(\langle M\rangle w\) and simulates \(M\) on \(w\). Like an interpreter running a program — it is why one computer can run any
program. It also shows the set of TMs is countable (they are strings).
