8. Precedence and associativity PL

Intuition

Without parentheses, 2 + 3 * 4 could mean 20 or 14. The language must decide. Precedence: which operator wins between different operators (* beats +). Associativity: which side wins between equal operators (10 - 4 - 3 is (10 - 4) - 3).

8.1 Common rules

Level (high → low)OperatorsAssociativity
1^ / ** (power)right: 2^3^2 = 2^(3^2) = 512

In Haskell you can even declare them: infixl 6 +, infixl 7 *, infixr 8 ^, infixr 5 :, infixr 5 ++. Function application binds tighter than any operator: f x + 1 = (f x) + 1.

8.2 How a grammar encodes them

Recipe: one variable per precedence level 
expr   → expr + term   | expr - term   | term       (lowest precedence, left-assoc)
term   → term * factor | term / factor | factor
factor → base ^ factor | base                         (right-assoc: RIGHT recursion)
base   → number | ( expr )                            (highest: parentheses)
  • Lower in the grammar = binds tighter: a term is built before it can be added.
  • Left recursion (expr → expr + term) grows the tree to the left ⇒ left associative.
  • Right recursion (factor → base ^ factor) ⇒ right associative.

This grammar is unambiguous: 2 + 3 * 4 has exactly one tree, with * below +:

digraph{node[shape=plaintext fontname="Helvetica"]; edge[arrowhead=none]; e[label="expr"]; e2[label="expr"]; p[label="+"]; t[label="term"]; t2[label="term"]; f2[label="factor"]; n2[label="2"]; t3[label="term"]; m[label="*"]; f4[label="factor"]; f3[label="factor"]; n3[label="3"]; n4[label="4"]; e->e2; e->p; e->t; e2->t2; t2->f2; f2->n2; t->t3; t->m; t->f4; t3->f3; f3->n3; f4->n4;}

A working parser built exactly this way (in Haskell) is in Chapter 22; it really turns 10 - 4 - 3 into (10 - 4) - 3.

Model answer (6 p): “Briefly describe precedence and associativity. How are they related?”

Precedence decides which of two different operators binds tighter when there are no parentheses: * has higher precedence than +, so 2 + 3 * 4 = 2 + (3 * 4) = 14. Associativity decides how operators of the same precedence level are grouped: - is left-associative, so 10 - 4 - 3 = (10 - 4) - 3 = 3; exponentiation and assignment are usually right-associative (2^3^2 = 2^(3^2), a = b = 0).

Relation: both are rules that remove the ambiguity of expressions without parentheses and thereby fix the shape of the syntax tree (and so the result). Precedence is used between different levels; associativity only matters when operators have the same precedence. In a grammar they are encoded by one non-terminal per precedence level (lower levels deeper in the tree bind tighter) and by the direction of recursion (left recursion ⇒ left associative, right recursion ⇒ right associative). Parentheses override both.
