7. Context-free grammars BOTH

Intuition: rules for rewriting

A grammar is a set of rewrite rules. Start with the symbol \(S\) and keep replacing a variable (capital letter) by the right side of one of its rules, until only letters (terminals) remain. Every string you can reach this way is in the language.

What grammars can do and automata can’t: matching things that are far apart. The rule \(S\to aSb\) puts an \(a\) on the left and a \(b\) on the right at the same time — that’s how you get “the same number of a’s and b’s”. That’s also how programming languages match ( with ) and { with }.

7.1 Definitions

Context-free grammar

\(G=(V,T,S,P)\) (Linz) or \(G=(N,\Sigma,R,S)\) (the PL exam): \(V\)/\(N\) = variables (non-terminals), \(T\)/\(\Sigma\) = terminals, \(S\) = start variable, \(P\)/\(R\) = productions of the form \(A\to x\) where \(A\) is one variable and \(x\) is any string of variables and terminals. “Context-free” = you may replace \(A\) no matter what surrounds it.

\(L(G)=\{w\in T^*\mid S\Rightarrow^* w\}\). A language is context-free if some CFG generates it.

  • Derivation: a sequence of rewrites \(S\Rightarrow aSb\Rightarrow aaSbb\Rightarrow aabb\).
  • Leftmost derivation: always rewrite the leftmost variable. Rightmost: always the rightmost.
  • Derivation (parse) tree: root \(S\); each rewrite \(A\to x\) gives \(A\) children = the symbols of \(x\); the leaves read left to right give the string.
  • Ambiguous grammar: some string has two different parse trees (equivalently, two different leftmost derivations).

Example: derivations and a tree

Grammar \(S\to aSbS\mid\lambda\), string \(abab\). Leftmost derivation: \(S\Rightarrow aSbS\Rightarrow abS\Rightarrow abaSbS\Rightarrow ababS\Rightarrow abab\).

7.2 The grammar recipe book

Almost every “construct a CFG” exam question is a combination of these patterns. All of them were checked by computer on every string up to length 10–12.

The core trick: build from the outside in

If two things must be equal in number and they are on opposite sides, generate them together with a rule like \(S\to aSb\). Whatever is “in the middle” gets its own variable.

7.3 The PL exam questions, solved slowly


2023-03-16 / 2023-05-05 Problem 2 (10 p, asked twice)


\(L_1\) = strings over \(\{a,b\}\) with (I) exactly as many \(a\) as \(b\) and (II) every prefix has at least as
many \(a\) as \(b\). Examples: \(\varepsilon, ab, aabb, aababbab\).


Understand it first. Read \(a\) as “(” and \(b\) as “)”. Then (I)+(II) says: the parentheses are balanced.
\(aababbab\) = (()())().


Build it. A non-empty balanced string starts with “(”. That “(” is closed by some “)”. What is between them is balanced,
and what comes after is balanced. So \(w = a\,u\,b\,v\) with \(u,v\in L_1\):


Answer

\(S\to aSbS\mid\varepsilon\)


Check: \(S\Rightarrow aSbS\Rightarrow abS\Rightarrow ab\). \(aabb\): \(S\Rightarrow aSbS\Rightarrow aaSbSbS\Rightarrow^* aabb\).
\(ba\) cannot be produced since every rule starts with \(a\). Also correct: \(S\to SS\mid aSb\mid\varepsilon\) (but ambiguous).





2023-05-05 Problem 1 (10 p): \(L=\{a^nb^m\mid n\ne 2m\}\)


The exam contradicts itself

The formula says \(n\ne 2m\) (#a ≠ 2·#b). The Swedish sentence says “antalet a inte är exakt hälften av antalet b”

Plan (formula reading). The strings with \(n=2m\) are exactly R2′: \(E\to aaEb\mid\lambda\). “≠” means \(n>2m\) or \(n<2m\):


    
  
  • \(n>2m\): an \(E\)-string with at least one extra \(a\) in front: \(A\to aA\mid aE\).
    • 
  
  • \(n<2m\): every \(b\) comes with 0, 1 or 2 \(a\)’s, and at least one \(b\) comes with fewer than 2:
    \(B\to aaBb\mid aUb\mid Ub\), with \(U\to aaUb\mid aUb\mid Ub\mid\lambda\) (\(U\) = “each b with at most 2 a’s”).
    • 



Answer (formula: \(n\ne2m\))

\(S\to A\mid B\quad A\to aA\mid aE\quad E\to aaEb\mid\lambda\quad B\to aaBb\mid aUb\mid Ub\quad U\to aaUb\mid aUb\mid Ub\mid\lambda\)


Answer (sentence: \(m\ne2n\))

\(S\to A\mid B\quad A\to Ab\mid Eb\quad E\to aEbb\mid\lambda\quad B\to aBbb\mid aUb\mid aU\quad U\to aUbb\mid aUb\mid aU\mid\lambda\)

\(S\to SB\mid aA\mid cCb,\ A\to aAb\mid\varepsilon,\ B\to BB\mid C,\ C\to\varepsilon\). Candidates:
ε, abcb, aabcb, cbab, abc, acb, aaabbbbcccbb, aaabbbbccbbcc, ccbbbaab.

  1. \(C\to\varepsilon\) only: \(C\) generates only \(\varepsilon\).

7.4 Ambiguity


\(E\to E+E\mid E*E\mid a\) is ambiguous: \(a+a*a\) has two trees, one meaning \(a+(a*a)\), one \((a+a)*a\).
A compiler needs one meaning, so we rewrite the grammar with levels (Chapter 8). Another classic is the
dangling else: in if c1 then if c2 then s1 else s2, which if owns the else?
(Rule in most languages: the nearest one.)


To show a grammar is ambiguous

Give one string and two different leftmost derivations (or two trees) for it. That’s a complete answer.





Always test your grammar before moving on (1 minute)

  1. Can it produce the shortest member (often ε)? Should it?
    2. 

  2. Derive 2 members from the examples.
    3. 

  3. Try to produce 1 non-member — make sure you can’t.
