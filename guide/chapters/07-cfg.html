7. Grammars: describing things that nest BOTH

Think about brackets in code: { if (x) { while (y) { … } } }. Every opening bracket needs its partner, and they nest inside each other. We just proved finite machines can’t handle this. So how do programming languages describe their own syntax? With a grammar. This chapter is worth more points than any other on the PL exam — so let’s take it slowly.

7.1 A grammar is a set of rewrite rules

The game

You start with one symbol, \(S\). You have rules like \(S\to aSb\) (“you may replace \(S\) by \(aSb\)”). You keep replacing capital letters using the rules until only small letters are left. Every string you can end up with is in the language.

Let’s play with the grammar \(S\to aSb\mid\lambda\) (the bar \(|\) means “or”: two rules, \(S\to aSb\) and \(S\to\lambda\)):

\(S \Rightarrow aSb \Rightarrow aaSbb \Rightarrow aaaSbbb \Rightarrow aaabbb\)

Look at what happened. Each time we used \(S\to aSb\), an a appeared on the left and a b on the right, at the same time. The a’s and b’s are created in pairs, wrapped around the middle. So the counts are always equal: this grammar generates exactly \(\{a^nb^n\}\) — the language no finite machine could handle!

That’s the superpower of grammars in one sentence: a rule can put things on both sides at once, which is exactly how you match partners that are far apart — a’s with b’s, ( with ), begin with end.

Definition — context-free grammar

\(G=(V,T,S,P)\) — written \(G=(N,\Sigma,R,S)\) on the PL exam: variables (non-terminals, capital letters), terminals (the alphabet, small letters), a start variable \(S\), and productions \(A\to x\) where the left side is a single variable. “Context-free” means you may rewrite \(A\) whatever is around it.

The language \(L(G)\) is all terminal strings you can derive from \(S\).

7.2 Derivations and trees

A derivation is the sequence of rewrites. When there are several variables to choose from, a leftmost derivation always rewrites the leftmost one. Example with \(S\to aSbS\mid\lambda\) and the string \(abab\):

\(S\Rightarrow aSbS\Rightarrow abS\Rightarrow abaSbS\Rightarrow ababS\Rightarrow abab\)

The same thing drawn as a parse tree — each rewrite becomes a node with its children:

Read the leaves left to right and you get the string. This tree is what a parser builds from your code — hold on to that picture, it comes back in Chapter 22.

7.3 How to design a grammar — think from the outside in

Designing grammars feels hard only until you learn to see a few shapes. Here is the way of thinking I want you to practise:

The method
  1. Write 3 members and 3 non-members (Chapter 1’s habit).
  2. Look for things that must match in number. If they are on opposite sides, create them together with one rule: \(S\to aSb\).
  3. Whatever sits in the middle, or is free, gets its own variable.
  4. “or” in the description = separate alternatives \(S\to S_1\mid S_2\). “followed by” = \(S\to S_1S_2\).
  5. Test: shortest member (λ?), two longer members, one non-member.

Let’s grow a family of grammars, each a small change of the last. Watch how the idea evolves:

Step 1 — exactly matched: \(a^nb^n\)

\(S\to aSb\mid\lambda\). One a, one b, at the same time.

Step 2 — a different ratio: \(a^nb^{2n}\)

Every a needs two b’s. So create them together: \(S\to aSbb\mid\lambda\). (And \(a^{2n}b^n\) is \(S\to aaSb\mid\lambda\).)

Step 3 — “at most”: \(a^nb^m\) with \(n\le m\)

Now there may be extra b’s. Matched pairs as before, plus a rule that adds a lone b: \(S\to aSb\mid Sb\mid\lambda\).

Step 4 — “not equal”: \(a^nb^m\) with \(n\ne m\)

This is the one people freeze on. The secret: “not equal” means “more a’s OR more b’s”. So build the matched part from the outside, and put at least one extra letter in the middle:

\(S\to aSb\mid A\mid B\qquad A\to aA\mid a\qquad B\to bB\mid b\)

\(A\) is “one or more a’s”, \(B\) is “one or more b’s”. Try \(aaab\): \(S\Rightarrow aSb\Rightarrow aAb\Rightarrow aaAb\Rightarrow aaab\). ✔ And \(ab\)? You’d need to end with \(A\) or \(B\), which always add at least one letter, so equal counts are impossible. ✔

Step 5 — three letters: \(a^nb^mc^{n+m}\)

The c’s must match the a’s and the b’s. Match a’s with the outer c’s first, then b’s with the inner c’s: \(S\to aSc\mid B,\ B\to bBc\mid\lambda\).

Step 6 — mirror images: palindromes

The first and last letters must be the same: \(S\to aSa\mid bSb\mid a\mid b\mid\lambda\).

Step 7 — order doesn’t matter: \(|w|_a=|w|_b\)

Now \(ba\) and \(abba\) are allowed. Idea: the first letter must be “paid back” by an opposite letter somewhere later: \(S\to aSbS\mid bSaS\mid\lambda\).

7.4 The real exam questions, solved slowly

“Equally many a and b, and every prefix has at least as many a as b” (10 p — asked twice)

This looks scary. It isn’t. Read a as “(” and b as “)”. “Every prefix has at least as many ( as )” means you never close a bracket that wasn’t opened. “Equally many” means everything gets closed. So this is just correctly balanced brackets: \(aababbab\) = (()())().

Now think about any non-empty balanced string. It starts with “(”. That bracket is closed by some “)”. Between them: a balanced string. After it: another balanced string. So:

Answer

\(S\to aSbS\mid\varepsilon\)

Check: \(S\Rightarrow aSbS\Rightarrow abS\Rightarrow ab\). ✔ \(aabb\): \(S\Rightarrow aSbS\Rightarrow aaSbSbS\Rightarrow aabSbS\Rightarrow aabbS\Rightarrow aabb\). ✔ \(ba\): every rule that produces letters starts with \(a\), so impossible. ✔

\(\{a^nb^m\mid n\ne 2m\}\) (10 p)

Read carefully — this exam contradicted itself

The formula says \(n\ne2m\): the number of a’s is not twice the number of b’s. The Swedish sentence under it said the number of a’s is not half the number of b’s, which is \(m\ne2n\). If that happens to you: write one line saying which reading you answer, then answer it.

Same trick as step 4: “not equal” = “too many” or “too few”. The equal case is \(E\to aaEb\mid\lambda\) (two a’s per b).

  • Too many a’s (\(n>2m\)): an equal string with at least one extra a in front: \(A\to aA\mid aE\).
  • Too few a’s (\(n<2m\)): each b brings 0, 1 or 2 a’s — and at least one b brings fewer than 2: \(B\to aaBb\mid aUb\mid Ub\), where \(U\to aaUb\mid aUb\mid Ub\mid\lambda\) (“each b with at most two a’s”).
Answer (formula reading, \(n\ne 2m\))

\(S\to A\mid B\quad A\to aA\mid aE\quad E\to aaEb\mid\lambda\quad B\to aaBb\mid aUb\mid Ub\quad U\to aaUb\mid aUb\mid Ub\mid\lambda\)

Answer (sentence reading, \(m\ne 2n\))

\(S\to A\mid B\quad A\to Ab\mid Eb\quad E\to aEbb\mid\lambda\quad B\to aBbb\mid aUb\mid aU\quad U\to aUbb\mid aUb\mid aU\mid\lambda\)

“Which of these strings can G generate?” (10 p)

\(S\to SB\mid aA\mid cCb,\ A\to aAb\mid\varepsilon,\ B\to BB\mid C,\ C\to\varepsilon\). Nine candidate strings.

Don’t start trying strings. First ask of every variable: what can this produce? Start from the bottom:

  • \(C\) can only become \(\varepsilon\). Nothing else.
  • \(B\to BB\mid C\): any number of C’s — which are all nothing. So \(B\) also only gives \(\varepsilon\).
  • \(A\to aAb\mid\varepsilon\): that’s \(a^kb^k\).
  • So \(S\to SB\) adds nothing, \(S\to aA\) gives \(a\cdot a^kb^k=a^{k+1}b^k\), and \(S\to cCb\) gives just \(cb\).
Answer

\(L(G)=\{a^{k+1}b^k\mid k\ge0\}\cup\{cb\}=\{a, aab, aaabb,\dots\}\cup\{cb\}\). None of the nine strings has that shape (ε, abcb, aabcb, cbab, abc, acb, aaabbbbcccbb, aaabbbbccbbcc, ccbbbaab), so G generates none of them.

It feels wrong to answer “none” — trust your analysis. That’s the whole point of the question.

7.5 Ambiguity — when one string has two meanings

Consider \(E\to E+E\mid E*E\mid a\). The string \(a+a*a\) has two different parse trees: one where the \(+\) is on top (meaning \(a+(a*a)\)), one where the \(*\) is on top (meaning \((a+a)*a\)). A grammar with such a string is ambiguous.

For a programming language this is a disaster: 2+3*4 would mean both 14 and 20. How languages fix it is the subject of the next chapter. To prove a grammar ambiguous on the exam: give one string and two different parse trees (or two different leftmost derivations).

Your turn
  1. \(\{a^nb^mc^n\mid n,m\ge0\}\)   2. \(\{a^nb^m\mid m\le n\le2m\}\)   3. Odd-length strings whose middle letter is \(a\).
Answers

1. \(S\to aSc\mid B,\ B\to bB\mid\lambda\) — a’s wrap c’s, free b’s in the middle. 2. \(S\to aSb\mid aaSb\mid\lambda\) — each b takes one or two a’s. 3. \(S\to XSX\mid a,\ X\to a\mid b\) — any letter on each side, the centre is \(a\).

Where we’re going next. Ambiguity isn’t just a theory problem — every programming language must decide what 2 + 3 * 4 means. That decision is called precedence, and it’s built right into the grammar.
