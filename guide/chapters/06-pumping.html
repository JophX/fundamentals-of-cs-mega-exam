6. The pumping lemma for regular languages FCS

Intuition: the pigeonhole principle

A DFA with \(n\) states reading a string of length ≥ \(n\) visits \(n+1\) states — so some state repeats. The part of the string read between the two visits is a loop. You can go around that loop 0 times, twice, 100 times, and the DFA ends in the same place. So every long string in a regular language has a piece \(y\) near the start that can be pumped.

We use it backwards: find a language where pumping breaks the string — then it can’t be regular.

The lemma (as given in the exam appendix)

If \(L\) is regular, there is \(n\ge 1\) such that every \(w\in L\) with \(|w|\ge n\) can be written \(w=xyz\) with \(|xy|\le n\) and \(|y|\ge 1\), such that \(xy^iz\in L\) for all \(i\ge 0\).

Recipe: proving L is NOT regular — it’s a game
  1. Assume \(L\) is regular. Let \(n\) be the pumping constant. (The opponent picks \(n\) — you don’t know it.)
  2. You pick a string \(w\in L\) with \(|w|\ge n\), depending on \(n\). Choose it so that the first \(n\) letters are all the same letter — then \(y\) is trapped there.
  3. The opponent splits \(w=xyz\) with \(|xy|\le n\), \(|y|\ge1\). You must handle every possible split.
  4. You pick an \(i\) (usually 0 or 2) so that \(xy^iz\notin L\).
  5. Contradiction ⇒ \(L\) is not regular.

Example 1: \(L=\{a^kb^k\mid k\ge0\}\)

Assume regular, constant \(n\). Pick \(w=a^nb^n\in L\), \(|w|=2n\ge n\). Any split with \(|xy|\le n\) has \(xy\) inside the first \(n\) letters, which are all \(a\)’s, so \(y=a^j\) with \(j\ge1\). Pump \(i=2\): \(xy^2z=a^{n+j}b^n\). It has more \(a\)’s than \(b\)’s, so it is not in \(L\). Contradiction; \(L\) is not regular.

Example 2: \(L=\{ww^R\}\) (even palindromes)

Pick \(w=a^nbba^n\). \(y=a^j\) inside the first block. \(i=0\): \(a^{n-j}bba^n\) is not a palindrome. Not regular.

Pick \(w=a^nb^n\) again (it’s in \(L\)); same argument as Example 1. Alternative trick: if \(L\) were regular, then \(L\cap a^*b^*=\{a^nb^n\}\) would be regular (closure under ∩) — contradiction.

Where people lose points
  • Choosing a specific number like \(w=a^5b^5\). The string must depend on \(n\).
  • Choosing the split yourself (“let \(y=a\)”). You must argue for all splits.
  • Using the lemma to prove a language is regular. It can’t do that (it is only a necessary condition).
  • Forgetting to say “contradiction, so \(L\) is not regular” at the end.
