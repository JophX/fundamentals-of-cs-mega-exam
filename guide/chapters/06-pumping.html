6. Proving a language is NOT regular: the pumping lemma FCS

It’s easy to show a language is regular: build the machine. But how do you show that no machine exists — not one you failed to find, but one that cannot exist? You need a property every regular language has, and then show your language doesn’t have it.

6.1 Where the property comes from

The pigeonhole idea

Take a DFA with, say, 5 states. Feed it a string of length 5 or more. Reading 5 letters it passes through 6 states — but there are only 5. So some state repeats. (Six pigeons, five holes: two pigeons share a hole.)

The letters read between the two visits to that state form a loop in the machine. Now here’s the key: the machine can’t tell how many times it went around that loop. Go around zero times, twice, a hundred times — it ends up in the same place at the end, so it gives the same verdict.

So in every long enough accepted string there’s a piece near the start — call it \(y\) — that you can pump: delete it, or repeat it, and the string stays in the language.

Written formally (you get this on the exam’s definition sheet):

Pumping lemma for regular languages

If \(L\) is regular, there is a number \(n\) such that every \(w\in L\) with \(|w|\ge n\) can be split as \(w=xyz\) with \(|xy|\le n\), \(|y|\ge1\), and \(xy^iz\in L\) for every \(i\ge0\).

(\(n\) is the number of states; \(|xy|\le n\) because the repeat happens within the first \(n\) letters; \(|y|\ge1\) because a loop reads at least one letter.)

6.2 Using it: think of it as a game

To prove \(L\) is not regular, you play a game against an opponent who claims it is — and you show you can always win:

  1. Opponent: “It’s regular, and my pumping number is \(n\).” (You don’t know \(n\) — work with the letter.)
  2. You: pick a string \(w\) in \(L\) of length at least \(n\). This is your big move. Choose it so the first \(n\) letters are all the same — then the opponent’s \(y\) is trapped there.
  3. Opponent: splits \(w=xyz\) any way they like, as long as \(|xy|\le n\), \(|y|\ge1\). You must beat every possible split.
  4. You: pick how many times to pump (\(i=0\) or \(i=2\) usually) so the result falls out of \(L\).
  5. You won ⇒ contradiction ⇒ \(L\) is not regular.

The classic: \(\{a^kb^k\mid k\ge0\}\)

Assume \(L\) is regular with pumping number \(n\). Choose \(w=a^nb^n\) — it’s in \(L\) and has length \(2n\ge n\). Whatever split the opponent chooses, \(|xy|\le n\) means \(x\) and \(y\) sit inside the first \(n\) letters, which are all a’s. So \(y=a^j\) for some \(j\ge1\). Pump with \(i=2\): \(xy^2z=a^{n+j}b^n\) — more a’s than b’s, not in \(L\). Contradiction, so \(L\) is not regular.

Read that proof again and notice how little there is to it. The choice \(w=a^nb^n\) did all the work: it forced \(y\) to be only a’s.

More, same pattern

  • \(\{ww^R\}\): choose \(w=a^nbba^n\). \(y\) is a’s from the first block; \(i=0\) makes the halves unequal — not a palindrome.
  • \(\{a^nb^m\mid n>m\}\): choose \(w=a^{n+1}b^n\); \(i=0\) removes at least one a, leaving #a ≤ #b.
  • \(\{a^{k^2}\}\): choose \(w=a^{n^2}\); \(i=2\) gives length between \(n^2\) and \(n^2+n<(n+1)^2\) — not a square.
  • \(\{w\mid |w|_a=|w|_b\}\): a shortcut! If it were regular, so would be its intersection with the regular \(a^*b^*\) — but that’s \(\{a^nb^n\}\). Closure properties can prove non-regularity too.
How these proofs lose points
  • Picking a concrete number like \(w=a^5b^5\). Your string must use \(n\).
  • Choosing the split yourself (“let \(y=a\)”). The opponent chooses; you must handle all splits.
  • Trying to use the lemma to prove a language is regular. It can’t — it only rules things out.
  • Forgetting the last sentence: “contradiction, so \(L\) is not regular.”
