1. Strings, languages and the notation you must be able to read

The one idea behind both courses

A language is nothing mysterious: it is just a set of strings. “All strings of a’s and b’s with an even number of b’s” is a language. “All syntactically correct Java programs” is a language. The whole of formal language theory asks two questions: how do I describe such a set with a finite recipe (a grammar, a regular expression, a machine), and how powerful does the recipe have to be?

1.1 Alphabets and strings

Definition
  • An alphabet \(\Sigma\) is a finite, non-empty set of symbols, e.g. \(\Sigma = \{a, b\}\).
  • A string (word) over \(\Sigma\) is a finite sequence of symbols: \(abba\).
  • The empty string has no symbols. Linz (the FCS book) writes it \(\lambda\); the PL exam and Sipser write it \(\varepsilon\). They are the same thing.
  • \(|w|\) is the length of \(w\): \(|abba| = 4\), \(|\lambda| = 0\).
  • \(|w|_a\) is the number of \(a\)’s in \(w\): \(|abba|_a = 2\), \(|abba|_b = 2\).
  • \(w^R\) is \(w\) reversed: \((abc)^R = cba\).
  • \(a^n\) means \(n\) copies of \(a\): \(a^3 = aaa\), \(a^0 = \lambda\).

Concatenation just glues strings: if \(u = ab\) and \(v = ba\) then \(uv = abba\). Note that \(\lambda w = w\lambda = w\) — the empty string is the “do nothing” of concatenation, like 0 for addition.

Prefix, suffix, substring. \(u\) is a prefix of \(w\) if \(w = uv\) for some \(v\). The PL exam explains it for you: the prefixes of \(abca\) are \(\varepsilon, a, ab, abc, abca\). A suffix is the same from the other end; a substring is any contiguous piece.

1.2 Languages and operations on them

Definition
  • \(\Sigma^*\) = the set of all strings over \(\Sigma\), including \(\lambda\). For \(\Sigma=\{a,b\}\): \(\Sigma^* = \{\lambda, a, b, aa, ab, ba, bb, aaa, \dots\}\).
  • \(\Sigma^+ = \Sigma^* \setminus \{\lambda\}\) (all non-empty strings).
  • A language over \(\Sigma\) is any subset \(L \subseteq \Sigma^*\).

Because languages are sets, all set operations work: union \(L_1 \cup L_2\), intersection \(L_1\cap L_2\), difference \(L_1 \setminus L_2\), complement \(\overline{L} = \Sigma^* \setminus L\). Two extra operations only make sense for languages:

  • Concatenation: \(L_1L_2 = \{uv \mid u\in L_1, v\in L_2\}\). Example: \(\{a,ab\}\{b\} = \{ab, abb\}\).
  • Star (Kleene closure): \(L^* = \{\lambda\}\cup L\cup LL\cup LLL\cup\cdots\) — glue together any number (including zero) of strings from \(L\). Example: \(\{ab\}^* = \{\lambda, ab, abab, ababab,\dots\}\).
Trap: three different “empty” things

\(\emptyset\) is the empty language (no strings at all). \(\{\lambda\}\) is a language containing exactly one string, the empty one. \(\lambda\) itself is a string. So \(|\emptyset| = 0\) but \(|\{\lambda\}| = 1\). Also \(\emptyset^* = \{\lambda\}\) (zero pieces glued together is the empty string).

1.3 Reading set-builder notation (the exams are full of it)

\(\{\, w \in \{a,b\}^* \mid \text{condition} \,\}\) reads “all strings \(w\) made of a’s and b’s such that the condition holds”. Practise translating until it is automatic:

NotationIn wordsSome membersSome non-members
\(\{a^nb^n \mid n\ge 0\}\)some a’s followed by the same number of b’s\(\lambda, ab, aabb\)\(aab, ba, abab\)
\(\{a^nb^m \mid n\ne 2m\}\)a’s then b’s, and #a is not twice #b\(a, b, ab, aaab\)\(\lambda, aab, aaaabb\)
\(\{w \mid |w|_a = |w|_b\}\)equally many a’s and b’s, any order\(\lambda, ab, ba, abba\)\(a, aab\)
\(\{ww^R \mid w\in\{a,b\}^*\}\)even-length palindromes\(\lambda, aa, abba\)\(aba, ab\)
\(\{a^{n^2}\mid n\ge 0\}\)a’s, where the count is a perfect square\(\lambda, a, a^4, a^9\)\(aa, aaa\)
\(\{w \mid |w|_a > 2|w|_b\}\)more than twice as many a’s as b’s\(a, aaab, aaba\)\(\lambda, aab\)

Notice the difference between \(a^nb^n\) (order is forced: all a’s first) and \(|w|_a=|w|_b\) (order is free). Mixing those two up is a classic way to build the wrong grammar.

Exam habit

Before you build anything for a language, write down 3 members and 3 non-members, including the shortest ones (is \(\lambda\) in it?). This takes 30 seconds and catches most misunderstandings.

1.4 Proof words you will need

  • “Closed under X”: doing X to languages in the class always gives a language in the class. “Regular languages are closed under union” = the union of two regular languages is always regular.
  • Proof by contradiction: assume the opposite, derive something impossible. All pumping-lemma proofs and the halting-problem proof work like this.
  • Proof by construction: show something exists by building it (e.g. build a DFA for the union).
  • Countable: can be listed as item 1, item 2, item 3, … (Chapter 13). \(\Sigma^*\) is countable: list strings by length, then alphabetically.
  • \(\mathbb{N} = \{0, 1, 2, \dots\}\) in this course (the pumping lemma appendix says “for all \(i\in\mathbb{N}\) (including 0)”).
Check yourself
  1. Is \(\lambda \in \{a^nb^m \mid n\ne 2m\}\)?
  2. List all strings of \(\{a,b\}^*\) of length 2.
  3. What is \(\{a, b\}\{\lambda, a\}\)?
  4. What is \(|aabab|_b\)?
