1. The language of languages BOTH

Before we build any machine, we need to agree on what a machine is for. Here is the simplest possible job: someone hands you a string of symbols, and you must answer yes or no.

  • Is x1 = 3.14; a correctly formed Java statement? Yes/no.
  • Is ((a+b)*c correctly bracketed? Yes/no.
  • Is abba a palindrome? Yes/no.

Every one of these questions is secretly the same question: is this string in the set of “good” strings? That set is what we call a language. That’s the whole idea. Not English, not Java — just a set of strings. Everything in both courses is about describing such sets and building machines that decide membership in them.

1.1 The building blocks

An alphabet \(\Sigma\) is the set of symbols we’re allowed to use — like the keys on a keyboard. We’ll usually use \(\Sigma=\{a,b\}\) because two symbols are enough to show every interesting idea, and small examples are easier to think about.

A string is a finite sequence of symbols: \(abba\), \(b\), \(aaaa\). And there is one very special string: the empty string, with no symbols at all. It’s written \(\lambda\) (lambda) in the FCS course and \(\varepsilon\) (epsilon) on the PL exam. Same thing, two names.

Why does the empty string matter so much?

Because it’s the easiest thing to forget. Is the empty file a valid program? Is “no brackets at all” balanced? Many exam answers are wrong only because they forgot to decide whether \(\lambda\) belongs. Think of \(\lambda\) as the number 0 of strings: gluing it onto anything changes nothing, \(\lambda w = w\).

A few pieces of notation you’ll see constantly — each one is simple:

1.2 Languages are sets — so we can combine them

\(\Sigma^*\) (“sigma star”) is the set of all strings over the alphabet, including \(\lambda\): \(\{\lambda, a, b, aa, ab, ba, bb, aaa,\dots\}\). A language is just some subset of it — the strings we call “good”.

Since languages are sets, you can take unions, intersections and complements, exactly as in any maths course. Two more operations are special to languages, and you should picture them rather than memorise them:

  • Concatenation \(L_1L_2\): pick one string from \(L_1\), one from \(L_2\), glue them. Every combination. \(\{a,ab\}\{b\}=\{ab,abb\}\).
  • Star \(L^*\): glue together any number of strings from \(L\) — including zero of them, which gives \(\lambda\). \(\{ab\}^*=\{\lambda, ab, abab, ababab,\dots\}\). Think of it as “repeat as often as you like”.
Three kinds of “nothing”

\(\emptyset\) is a language with no strings (an empty bag). \(\{\lambda\}\) is a language with one string, the empty one (a bag containing an empty envelope). \(\lambda\) is a string (the empty envelope itself). They are different, and examiners love checking whether you know it.

1.3 Learning to read the exam’s notation

Exam questions describe languages in set-builder notation: \(\{\,w \mid \text{condition}\,\}\) means “all strings \(w\) for which the condition holds.” The single most useful habit I can give you:

The 30-second habit that saves points

Before you build anything for a language, write down three strings that are in it and three that are not — starting with the shortest ones, and always deciding about \(\lambda\). If you can’t do this, you don’t understand the question yet, and nothing you build will be right.

Let’s practise on languages that really appear on the exams. Cover the right-hand columns and try first.

LanguageIn wordsIn itNot in it
\(\{a^nb^n\mid n\ge0\}\)a block of a’s, then the same number of b’s\(\lambda, ab, aabb\)\(aab, ba, abab\)
\(\{a^nb^m\mid n\ne 2m\}\)a’s then b’s, and #a is not twice #b\(a, b, ab, aaab\)\(\lambda, aab, aaaabb\)
\(\{w\mid |w|_a=|w|_b\}\)equally many a’s and b’s, in any order\(\lambda, ba, abba\)\(a, aab\)
\(\{ww^R\}\)a string followed by its mirror image\(\lambda, aa, abba\)\(aba, ab\)

Look closely at the first and third rows. \(a^nb^n\) forces the order — all a’s first. \(|w|_a=|w|_b\) doesn’t care about order at all: \(ba\) is fine. Confusing those two is one of the most common reasons a grammar answer gets zero.

Your turn
  1. Is \(\lambda\) in \(\{a^nb^m\mid n\ne 2m\}\)?
  2. Write all strings in \(\{a,b\}^*\) of length 2.
  3. What is \(\{a,b\}\{\lambda,a\}\)?
  4. Give three members of \(\{w\mid w \text{ has an odd number of } b\text{’s}\}\).
Answers

1. No — \(\lambda=a^0b^0\) and \(0=2\cdot0\), so the condition fails. 2. \(aa,ab,ba,bb\). 3. \(\{a,aa,b,ba\}\). 4. For example \(b\), \(ab\), \(bbb\) — any string where the number of \(b\)’s is odd.
