24. Two other ways to think: functional and logic languages PL

24.1 The functional family

You’ve spent all of Part III inside Haskell, so you already know the functional way of thinking. Here it is in a sentence: a program is a set of function definitions, and a function’s result depends only on its arguments — no hidden state, no side effects. The family tree: LISP (1958!) → Scheme, ML, Haskell, Erlang.

Here is the same function — “is a in the list?” — in three of them. Notice they all say the same thing: an empty list contains nothing; otherwise, check the first element, or look in the rest.

; Scheme
(DEFINE (member a lst)
  (COND ((NULL? lst) #F)
        ((EQ? a (CAR lst)) #T)
        (ELSE (member a (CDR lst)))))

(* ML *)
fun member a []     = false
  | member a (b::l) = a = b orelse member a l

-- Haskell
member a []    = False
member a (b:l) = a == b || member a l

Haskell goes further than most: it is purely functional and lazy — nothing is computed until it’s needed, which is why an infinite list like [n*n | n <- [0..]] is perfectly fine.

Why people love functional languages

Programs are easier to prove correct and to transform (a name always means the same value); functions are first-class (pass them around like data); the syntax and meaning are small and clean; and with no shared changing state, parallel execution is much safer. Downsides: on ordinary hardware they can be slower, and input/output and state are awkward. The ideas have spread everywhere: Java, JavaScript, Python, Ruby and C# all have lambdas and pass functions as parameters.

24.2 Logic programming: say what, not how

Every language so far makes you describe how to compute something. Logic programming flips that. You describe what is true — facts and rules — and then ask questions. A built-in search engine works out the answer.

Think about sorting. In Java you write the steps of an algorithm. In a logic language you could say: “a sorted version of a list is a rearrangement of it in which every element is ≤ the next” — and that description is the program.
