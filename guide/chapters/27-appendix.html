Appendix A. Cheat sheets

Automata & regular
  • DFA 5-tuple; δ total. NFA: δ → sets, λ-moves. NFA→DFA: sets of states + λ-closure; final if contains a final.
  • Regex: star > concat > union (+).
  • Closed: ∪ ∩ complement concat star reverse difference. Complement needs a complete DFA.
  • Pumping: w = xyz, |xy| ≤ n, |y| ≥ 1. Pick w from n; all splits; pump 0 or 2.
  • Minimize: mark final/non-final pairs; repeat; merge unmarked.
Context-free
  • aSb matches pairs. ≠ = < ∪ >. “or” = S → S₁ | S₂.
  • Balanced: S → aSbS | λ. Equal count: S → aSbS | bSaS | λ.
  • CNF: λ → units → useless → terminals → split.
  • CYK: V_ii from A→a; V_ij over all cuts k with A→BC; S ∈ V_1n ⇒ member.
  • CF pumping: xuyvz, |uyv| ≤ n, |uv| ≥ 1, window anywhere.
  • CFL closed: ∪, concat, star, ∩regular. Not: ∩, complement.
Computability
  • TM 7-tuple; halts when δ undefined.
  • Regular ⊂ DCFL ⊂ CFL ⊂ (CSL) ⊂ Recursive ⊂ RE.
  • L and L̄ RE ⇒ L recursive. Halting: RE, not recursive; its complement not RE.
  • Reduce known-undecidable → new problem.
  • NP: poly verifier / NTM. NP-complete: in NP + reduction from known NPC.
Haskell
  • Signature, base case, recursive case, trace.
  • Accumulator: go xs acc; go [] acc = acc.
  • foldl f acc (x:xs) = foldl f (f acc x) xs
  • foldr f acc (x:xs) = f x (foldr f acc xs)
  • x : xs is O(1); xs ++ ys is O(|xs|).
  • listToInt: acc*10 + d. decompress: replicate n c ++ rest.
PL concepts
  • Encapsulation = grouping in one unit. Information hiding = internals inaccessible.
  • Polymorphism: subtype, parametric, ad hoc.
  • Lexer → tokens; parser → AST (+ precedence); executor → environments, call stack, heap.
  • Value = copy; reference = alias; result; value-result; name.
  • Static scope = text; dynamic = call chain.
  • Semaphore wait/signal; monitor; messages; transactional memory.
