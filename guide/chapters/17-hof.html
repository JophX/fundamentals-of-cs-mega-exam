17. Higher-order functions: map, filter, fold, lambda PL

Functions are values

In Haskell a function can be passed as an argument and returned as a result (“first-class citizens”). A function that takes or returns a function is higher-order. map, filter and fold capture the three most common loops once and for all: transform every element, keep some elements, combine all elements into one value.

17.1 Lambdas, currying, sections, composition

(\x y -> x * y + 1) 3 4


    
  
  • Lambda: \x -> x * 3 is a function without a name.

  • Currying: every function takes one argument at a time. add3 :: Int -> Int -> Int -> Int really means
    Int -> (Int -> (Int -> Int)). So add3 1 is a function waiting for two more
    (partial application).
    • 
  
  • Sections: (+ 5), (* 2), (> 3), (`div` 2) are operators with one
    side filled in.
    • 
  
  • Composition: (f . g) x = f (g x) — read right to left. f $ x = f x (saves parentheses).

17.3 Folds


Intuition

foldl f z [x1,x2,x3] = f (f (f z x1) x2) x3 — start with z, eat the list from the left,
accumulator first.

foldr f z [x1,x2,x3] = f x1 (f x2 (f x3 z)) — replace each : by f and []
by z, element first.








foldl (-) 0 [1,2,3]
foldr (-) 0 [1,2,3]
foldr (:) [] [1,2,3]
foldl (\acc x -> x : acc) [] [1,2,3]




foldl (-) 0 [1,2,3]foldr (-) 0 [1,2,3]


((0-1)-2)-3 = -61-(2-(3-0)) = 2




Which fold?

    

  • Building a list in the same order (map-like): foldr.
    • 

  • Running total / “reading left to right” (sum, count, listToInt, reverse): foldl.
    • 

  • Works on infinite lists (lazily): only foldr.
    •
