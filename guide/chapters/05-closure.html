5. Closure and decision properties of regular languages FCS

Intuition

“Regular languages are closed under X” means: if you take regular languages and do X to them, the result is always regular again. To prove it you show how to build a machine (or regex) for the result from the machines for the inputs.

5.1 The closure properties and their one-line proofs

OperationClosed?Construction (the proof)
Union \(L_1\cup L_2\)yesregex \(r_1+r_2\); or product DFA with final = “\(p\in F_1\) or \(q\in F_2\)”
Concatenation \(L_1L_2\)yesregex \(r_1r_2\); or NFA: λ-arrows from finals of \(M_1\) to the start of \(M_2\)
Star \(L^*\)yesregex \(r^*\); or NFA with new start/final and λ-arrow back
Complement \(\overline L\)yestake a DFA (complete, with trap state) and swap final and non-final states
Intersection \(L_1\cap L_2\)yesproduct DFA with final = \(F_1\times F_2\); or \(\overline{\overline{L_1}\cup\overline{L_2}}\) (De Morgan)
Difference \(L_1\setminus L_2\)yes\(L_1\cap\overline{L_2}\)
Reversal \(L^R\)yesreverse all arrows, swap start and final (add a new start with λ to old finals)
Homomorphismyessubstitute a string for each letter in the regex
Complement needs a DFA

Swapping final/non-final in an NFA does not give the complement (a string may have one accepting and one rejecting path). Convert to a complete DFA first. That is a classic exam point.

Model answer — FCS 2022 Q2 (5 p): “Argue that regular languages are closed under complement, intersection, concatenation and union”

Let \(L_1, L_2\) be regular, with DFAs \(M_1 = (Q_1,\Sigma,\delta_1,q_1,F_1)\), \(M_2=(Q_2,\Sigma,\delta_2,q_2,F_2)\) and regular expressions \(r_1, r_2\).

Union: \(r_1 + r_2\) is a regular expression with \(L(r_1+r_2)=L_1\cup L_2\), so \(L_1\cup L_2\) is regular. Concatenation: likewise \(L(r_1r_2) = L_1L_2\). Complement: let \(M_1\) be complete (every state has a transition on every symbol; add a trap state if needed). The DFA \((Q_1,\Sigma,\delta_1,q_1,Q_1\setminus F_1)\) ends in exactly the same state as \(M_1\) on every input but accepts exactly when \(M_1\) rejects, so it accepts \(\overline{L_1}\). Intersection: the product DFA \((Q_1\times Q_2,\Sigma,\delta,(q_1,q_2),F_1\times F_2)\) with \(\delta((p,q),a)=(\delta_1(p,a),\delta_2(q,a))\) simulates both machines at once and accepts iff both accept, so it accepts \(L_1\cap L_2\). (Alternatively \(L_1\cap L_2=\overline{\overline{L_1}\cup\overline{L_2}}\) by De Morgan, using the previous two.)

Recipe for “necessarily” statements

“Necessarily” = always. To show false, find one counterexample — try the extreme languages first: \(\emptyset\), \(\{\lambda\}\), \(\Sigma^*\), a finite set.

5.3 Decision properties

For regular languages (given as DFA/NFA/regex) all these are decidable (there’s an algorithm that always answers):

  • Membership \(w\in L\)? Run the DFA.
  • Emptiness \(L=\emptyset\)? Is any final state reachable from the start state? (graph search)
  • Finiteness — is \(L\) infinite? Yes iff there is a cycle on some path from the start state to a final state (remove states that can’t reach a final state, then look for a cycle among the rest).
  • Equivalence \(L_1=L_2\)? Check \((L_1\setminus L_2)\cup(L_2\setminus L_1)=\emptyset\), or compare minimal DFAs.

5.4 The ☆ question: infinite unions (FCS 2022 Q9)

Model answer: “\(L_N=\bigcup_{n\in N}L_n\) with each \(L_n\) regular — necessarily regular?”

Disprove. Let \(N=\mathbb N\) and \(L_n=\{a^nb^n\}\). Each \(L_n\) contains one string, so it is finite and therefore regular. But \(\bigcup_{n\in\mathbb N}L_n=\{a^nb^n\mid n\ge 0\}\), which is not regular (pumping lemma, Chapter 6). So an infinite union of regular languages need not be regular. (Closure under union only extends to finite unions, by induction.)
