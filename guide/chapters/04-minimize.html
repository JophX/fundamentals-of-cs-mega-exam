4. Minimizing a DFA FCS

Intuition

Two states are the same in practice if, from either of them, exactly the same future strings lead to acceptance. Then you can merge them. The minimal DFA is the one where every state “means” something different.

Definition

States \(p\) and \(q\) are indistinguishable if for every string \(w\): \(\delta^*(p,w)\in F \iff \delta^*(q,w)\in F\). Otherwise they are distinguishable — some string \(w\) takes one to a final state and the other to a non-final state.

Recipe: the marking (table-filling) algorithm
  1. Remove states that can’t be reached from the start state.
  2. Draw a table with one cell for every pair of states.
  3. Round 0: mark every pair where one state is final and the other is not (the empty string distinguishes them).
  4. Repeat: for every unmarked pair \((p,q)\) and every letter \(a\): if \((\delta(p,a),\delta(q,a))\) is already marked, mark \((p,q)\). Stop when a whole round marks nothing new.
  5. Unmarked pairs are indistinguishable: merge them. Each group becomes one state of the minimal DFA.

Facts to know

    
  
  • The minimal DFA of a regular language is unique (up to renaming states).
    • 
  
  • Two DFAs accept the same language ⇔ their minimal DFAs are the same. So equivalence of regular languages is
    decidable.
    • 





Traps

  • Forgetting to delete unreachable states first.

  • Stopping after one round — keep going until a full round marks nothing.
