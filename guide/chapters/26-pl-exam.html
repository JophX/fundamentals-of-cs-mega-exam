26.4 Practice exam (60 p, 36 to pass) — 4 hours, no aids

  1. (10 p) Construct a CFG for \(\{a^nb^mc^k\mid k=n+m\}\). Then show a leftmost derivation of abcc.
  2. (10 p) Convert \(S\to aSb\mid bA\mid\lambda,\ A\to aA\mid a\) to Chomsky normal form.
  3. (6 p) Explain static vs dynamic scoping with an example where they give different results.
  4. (8 p) What is polymorphism? Describe three kinds with examples.
  5. (6 p) What is the difference between a compiler and an interpreter? What does the lexer produce?
  6. (10 p) Write countRuns :: String -> Int that counts the number of maximal runs of equal characters (countRuns "aaabbca" = 4), and myFoldr.
  7. (10 p) Write merge :: [Int] -> [Int] -> [Int] merging two sorted lists, and use it to write merge sort.
Solutions

1. \(S\to aSc\mid B,\ B\to bBc\mid\lambda\) (R5). \(S\Rightarrow aSc\Rightarrow aBc\Rightarrow abBcc\Rightarrow abcc\).

2. Nullable: S. Remove λ: \(S\to aSb\mid ab\mid bA\), \(A\to aA\mid a\). No units. CNF: \(S\to UX\mid UT\mid TA,\ X\to ST,\ A\to UA\mid a,\ U\to a,\ T\to b\).

3. Ch. 19.4 (the Python/bash example). 4. Ch. 21.3. 5. Ch. 22.

6. countRuns = length . compress (using compress from Ch. 16), or directly: countRuns [] = 0; countRuns (c:cs) = 1 + countRuns (dropWhile (== c) cs). myFoldr = foldr from Ch. 17.

7. Ch. 16 (merge, mergeSort).
